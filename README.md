# 📰 Techiewix News – Responsive News Website

Techiewix News is a modern **responsive news website** built using **HTML, CSS, and JavaScript**.
The project presents news articles in multiple categories such as technology, education, sports, and current affairs with a clean and attractive user interface.

## 🚀 Features

* Responsive news website layout
* Navigation bar with multiple categories
* Featured news banner section
* Hot topics / trending news section
* Top stories and latest news articles
* Modern UI design with images and headlines
* Newsletter subscription section
* Footer with important links

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Font Awesome Icons
